# font4x8.txt -- the NES client's text font: 64 columns on a 256-pixel line.
#
# Each glyph is a 4 x 8 cell drawn as eight rows of four pixels ('#' ink,
# '.' paper). Rows 0 and 7 must stay blank: src/nes/blit.s writes only rows
# 1-6 of a cell. Row 0 is the one that matters -- the MMC3 interrupt that
# switches pattern tables ahead of every eighth text row can land a few
# pixels into that row's first line, and a blank line there is what makes the
# switch invisible. tools/nes/mkgfx.py refuses a glyph that breaks either
# rule. Column 3 is the gap between letters by convention only; the rule
# glyphs run through it so a line of them joins up.
#
# There is no bold face. A three-pixel letter has nowhere to thicken into
# but the gap, and the result is unreadable; the inbox marks unread mail the
# way Gmail does instead, white paper for unread and grey for read.
#
