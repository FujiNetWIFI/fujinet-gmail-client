# sprites.txt -- the NES client's sprite art, for tools/nes/mkgfx.py.
#
# Every sprite is 8 x 16 (the client runs the PPU's tall-sprite mode), drawn
# here as sixteen rows of eight: '.' is transparent and '1' '2' '3' are the
# three colours of whichever sprite palette the sprite is placed with
# (src/nes/sprites.c). A block may be wider than eight -- "@name 16" -- and is
# then cut into 8-wide sprites left to right, named name_0, name_1, ...
#
# "@name 16 x2" doubles a block's pixels both ways before cutting it, which is
# how the splash screen's 32 x 32 mark is the header's 16 x 16 one and cannot
# drift from it: the doubled block is 32 wide and 32 tall, so it comes out as
# two rows of four sprites, top row first (name_0..name_3, then name_4..7).
#
# The Gmail mark. Blue left stroke, red V, yellow top-right corner, green
# right stroke -- the 2020 logo's four colours in the order a reader meets
# them. The left half is drawn with palette 0 (1 blue, 2 red) and the right
# half with palette 1 (1 green, 2 red, 3 yellow), because no one sprite
# palette holds all four.
